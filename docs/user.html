👤 User & Authentication APIs
user.routes.js
POST /api/v1/users/register
Public
Registers a new customer user account.
Supports standard credentials with multipart file upload for profile photo.
Validates duplicate emails and usernames before inserting user record.
📥 Request Format (Multipart / FormData)
{
  "username": "johndoe",
  "email": "john@example.com",
  "phone_number": "9876543210",
  "password": "Password123!",
  "profile_photo": "<File Attachment>"
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": {
    "user_id": "usr_991823",
    "username": "johndoe",
    "email": "john@example.com",
    "role": "user"
  },
  "message": "User registered successfully",
  "success": true
}

POST /api/v1/users/orgregister
Public
Submits a registration application for a new parking agency organization.
Uploads verification documents, trade licenses, Aadhaar details, and up to 10 facility photos.
Initializes application in 'pending' status awaiting Super Admin verification.
📥 Request Format (Multipart FormData)
{
  "org_name": "Central Plaza Parking",
  "username": "centralplaza",
  "email": "org@centralplaza.com",
  "phone_number": "9800011122",
  "password": "SecurePassword123",
  "org_address": "12 Main Street, City",
  "car_capacity": 50,
  "two_wheeler_capacity": 30,
  "profile_photo": "<File>",
  "verification_document": "<File>",
  "aadhaar_card": "<File>",
  "trade_license_document": "<File>",
  "org_media": ["<File 1>", "<File 2>"]
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": null,
  "message": "Organization registered successfully",
  "success": true
}

POST /api/v1/users/requests/:orgId/approve
verifyJWT super_admin
Approves a pending organization registration application.
Converts applicant account into an active Agency Admin and instantiates the agency record.
📌 Path Parameters
orgId: string (e.g. org_551)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "org_id": "org_551", "status": "approved" },
  "message": "Organization request approved successfully"
}

GET /api/v1/users/directory
verifyJWT super_admin | authority_admin
Paginated system-wide directory of all users (customers, agency owners, operators, admins).
Supports filtering by role, account status, and keyword search.
🔍 Query Parameters
page=1&limit=10&role=user&status=active&search=john
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "users": [
      { "user_id": "usr_991823", "username": "johndoe", "email": "john@example.com", "role": "user", "status": "active" }
    ],
    "total": 1,
    "page": 1,
    "totalPages": 1
  }
}
