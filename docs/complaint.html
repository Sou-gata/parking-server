🚨 Complaint Ticketing APIs
complaint.routes.js
POST /api/v1/complaints
verifyJWT
Creates a new complaint ticket regarding a booking dispute or facility issue.
Supports uploading up to 5 photo attachments as evidence.
📥 Request Format (Multipart FormData)
{
  "agency_id": "agency_881",
  "booking_id": "bk_99012",
  "subject": "Unauthorized extra charge at exit gate",
  "description": "Operator requested cash payment despite wallet deduction.",
  "attachments": ["<File 1>", "<File 2>"]
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": { "complaint_id": "cmp_301", "ticket_number": "TICK-90812", "status": "open" },
  "message": "Complaint filed successfully"
}
GET /api/v1/complaints/user-status
verifyJWT
Retrieves list of booking IDs that the authenticated user has filed complaints for, enabling UI dispute indicators.
🔑 Headers Required
Authorization: Bearer <JWT_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": ["bk_99012", "bk_99045"],
  "message": "User complaint status retrieved"
}
GET /api/v1/complaints/user
verifyJWT user | super_admin
Fetches complaints list with step timelines submitted by the authenticated user.
🔑 Headers Required
Authorization: Bearer <JWT_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "complaint_id": "cmp_301", "subject": "Unauthorized extra charge", "status": "in_progress", "created_at": "2026-08-12T14:00:00Z" }
  ]
}
GET /api/v1/complaints/agency
verifyJWT agency_admin | staff | authority_admin
Fetches complaints filed against agency facilities for operator and authority review.
🔍 Query Parameters
status=open&page=1&limit=10
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "complaint_id": "cmp_301", "ticket_number": "TICK-90812", "customer_name": "John Doe", "subject": "Unauthorized extra charge", "status": "open" }
  ]
}
GET /api/v1/complaints/admin
verifyJWT super_admin | authority_admin
Master system complaint inbox for Super Admins and Authority Admins.
🔍 Query Parameters
agency_id=agency_881&status=in_progress&page=1
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "complaints": [ { "complaint_id": "cmp_301", "agency_name": "Metro Parking Hub", "status": "in_progress" } ],
    "total": 1
  }
}
GET /api/v1/complaints/:complaintId
verifyJWT
Fetches single ticket details including timeline steps, internal notes, and attachments.
📌 Path Parameters
complaintId: string (e.g. cmp_301)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "complaint_id": "cmp_301",
    "subject": "Unauthorized extra charge",
    "description": "Operator requested cash...",
    "status": "in_progress",
    "attachments": ["uploads/att_1.png"],
    "timeline": [ { "step": "Created", "timestamp": "2026-08-12T14:00:00Z" } ]
  }
}
POST /api/v1/complaints/:complaintId/steps
verifyJWT user | agency_admin | super_admin | staff
Appends an update note or resolution progress step to ticket timeline.
📥 Request Body (JSON)
{
  "action_taken": "Contacted gate operator for shift log review",
  "note": "Operator confirmed receipt mistake."
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": { "step_id": "step_881", "action_taken": "Contacted gate operator..." },
  "message": "Timeline step added"
}
PUT /api/v1/complaints/:complaintId/status
verifyJWT agency_admin | super_admin | staff
Updates ticket progress status (open, in_progress, resolved, rejected, closed) and resolution notes.
📥 Request Body (JSON)
{
  "status": "resolved",
  "resolution_notes": "Cash amount refunded to customer wallet."
}
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "complaint_id": "cmp_301", "status": "resolved" },
  "message": "Complaint status updated"
}
