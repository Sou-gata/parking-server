POST /api/v1/bookings
verifyJWT
Creates a new parking reservation, checks vehicle slot availability, and deducts user wallet balance.
📥 Request Body (JSON)
{
  "agency_id": "agency_881",
  "vehicle_type": "car",
  "vehicle_number": "WB-02-AB-1234",
  "start_time": "2026-08-14T10:00:00Z",
  "end_time": "2026-08-14T14:00:00Z",
  "total_hours": 4,
  "total_amount": 160.00,
  "payment_method": "wallet"
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": {
    "booking_id": "bk_99012",
    "booking_code": "849201",
    "status": "confirmed",
    "qr_code": "data:image/png;base64,..."
  },
  "message": "Booking created successfully"
}

GET /api/v1/bookings/user/:userId
verifyJWT
Fetches all past, active, and upcoming bookings made by a specific customer.
🔍 Query Parameters
status=active&page=1&limit=10
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "booking_id": "bk_99012", "booking_code": "849201", "agency_name": "Metro Parking Hub", "status": "confirmed", "total_amount": 160.00 }
  ]
}
GET /api/v1/bookings/agency/:agencyId
verifyJWT
Fetches reservations for an agency facility to manage slot usage, check-ins, and check-outs.
🔍 Query Parameters
status=checked_in&date=2026-08-14
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "booking_id": "bk_99012", "booking_code": "849201", "customer_name": "John Doe", "vehicle_number": "WB-02-AB-1234", "status": "checked_in" }
  ]
}
GET /api/v1/bookings/code/:bookingCode
verifyJWT
Looks up full booking information using 6-digit booking code or scanned QR code payload.
📌 Path Parameters
bookingCode: string (e.g. 849201)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "booking_id": "bk_99012",
    "booking_code": "849201",
    "customer_name": "John Doe",
    "vehicle_number": "WB-02-AB-1234",
    "status": "confirmed",
    "start_time": "2026-08-14T10:00:00Z"
  }
}
GET /api/v1/bookings/cancel-preview/:bookingCode
verifyJWT
Calculates and previews estimated cancellation refund amount and fee deductions prior to confirmation.
📌 Path Parameters
bookingCode: string (e.g. 849201)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "booking_code": "849201",
    "original_amount": 160.00,
    "cancellation_fee": 16.00,
    "refund_amount": 144.00,
    "policy_notes": "10% fee applied according to agency cancellation window."
  }
}
