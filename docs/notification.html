🔔 Notification APIs
notification.routes.js
GET /api/v1/notifications
verifyJWT
Fetches notification messages feed for authenticated user with unread counter.
🔍 Query Parameters
page=1&limit=15&unread_only=true
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "unreadCount": 2,
    "notifications": [
      { "id": "notif_881", "title": "Booking Confirmed", "message": "Your booking #849201 is confirmed.", "is_read": false, "created_at": "2026-08-14T10:00:00Z" }
    ]
  }
}
PUT /api/v1/notifications/:id/read
verifyJWT
Marks a single notification message as read.
📌 Path Parameters
id: string (e.g. notif_881)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "id": "notif_881", "is_read": true },
  "message": "Notification marked as read"
}
PUT /api/v1/notifications/read-all
verifyJWT
Marks all notifications in user inbox as read.
🔑 Headers Required
Authorization: Bearer <JWT_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "message": "All notifications marked as read"
}
DELETE /api/v1/notifications/clear
verifyJWT
Clears and deletes all notification messages from user inbox.
🔑 Headers Required
Authorization: Bearer <JWT_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "message": "Notifications cleared successfully"
}
POST /api/v1/notifications/preferences
verifyJWT
Configures notification delivery channels (Email, Push notifications, SMS alerts).
📥 Request Body (JSON)
{
  "email_notifications": true,
  "push_notifications": true,
  "sms_alerts": false
}
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "email_notifications": true, "push_notifications": true, "sms_alerts": false },
  "message": "Preferences updated"
}
