wallet.routes.js
POST /api/v1/wallets/add
verifyJWT user | super_admin
Submits a wallet top-up request with payment reference number and screenshot receipt.
📥 Request Format (Multipart FormData)
{
  "amount": 500,
  "payment_method": "UPI",
  "transaction_ref": "UPI1928374650",
  "screenshot": "<File Attachment>"
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": { "transaction_id": "txn_9011", "amount": 500, "status": "pending" },
  "message": "Wallet top-up request submitted"
}
GET /api/v1/wallets/transactions
verifyJWT super_admin | authority_admin
Fetches full system-wide transaction history logs across all users and agencies.
🔍 Query Parameters
page=1&limit=20&type=credit&status=approved
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "transactions": [
      { "transaction_id": "txn_9011", "amount": 500.00, "type": "credit", "status": "approved" }
    ],
    "total": 1,
    "page": 1
  }
}

POST /api/v1/wallets/requests/:transactionId/approve

}
