🕒 Working Hours APIs
workingHours.routes.js
GET /api/v1/working-hours/agency/:agencyId
Public
Fetches weekly operating hours and 24/7 status for a target agency.
📌 Path Parameters
agencyId: string (e.g. agency_881)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "agency_id": "agency_881",
    "is_24_7": false,
    "schedule": {
      "monday": { "open": "08:00", "close": "22:00" },
      "tuesday": { "open": "08:00", "close": "22:00" }
    }
  }
}
PUT /api/v1/working-hours/agency/:agencyId
verifyJWT agency_admin | super_admin
Updates operating hours schedule or toggles 24/7 status. Submits request for admin verification if required.
📥 Request Body (JSON)
{
  "is_24_7": true,
  "opening_time": "00:00",
  "closing_time": "23:59"
}
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "is_24_7": true },
  "message": "Working hours update request submitted"
}
GET /api/v1/working-hours/pending
verifyJWT super_admin
Lists pending schedule change requests awaiting Super Admin verification.
🔑 Headers Required
Authorization: Bearer <SUPER_ADMIN_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "request_id": "wh_req_99", "agency_name": "Metro Parking Hub", "proposed_is_24_7": true, "status": "pending" }
  ]
}
POST /api/v1/working-hours/requests/:requestId/approve
verifyJWT super_admin
Approves pending agency schedule change request.
📌 Path Parameters
requestId: string (e.g. wh_req_99)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "request_id": "wh_req_99", "status": "approved" },
  "message": "Working hours request approved"
}
POST /api/v1/working-hours/requests/:requestId/reject
verifyJWT super_admin
Rejects pending working hours change request.
📥 Request Body (JSON)
{
  "reason": "Facility zone restricted during overnight hours"
}
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "request_id": "wh_req_99", "status": "rejected" },
  "message": "Working hours request rejected"
}
