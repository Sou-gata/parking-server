GET /api/v1/agencies/:id/media
Public
Fetches approved public media images and videos for a specific parking agency.
📌 Path Parameters
id: string (e.g. agency_881)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "media_id": "med_101", "file_path": "uploads/img_1.jpg", "media_type": "image", "is_approved": true }
  ]
}
GET /api/v1/agencies/:id/all-media
verifyJWT
Fetches all uploaded media items for an agency including pending and rejected status files.
🔑 Headers Required
Authorization: Bearer <JWT_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "media_id": "med_102", "file_path": "uploads/img_2.jpg", "status": "pending" }
  ]
}
GET /api/v1/agencies
Public
Lists active parking agencies with support for geolocation radius filtering.
Filter by latitude, longitude, distance radius, keyword search, and vehicle type.
🔍 Query Parameters
latitude=22.5726&longitude=88.3639&radius=5&vehicle_type=car&search=metro
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    {
      "agency_id": "agency_881",
      "agency_name": "Metro Parking Hub",
      "latitude": 22.5726,
      "longitude": 88.3639,
      "car_rate": 40,
      "available_car_slots": 18
    }
  ]
}
GET /api/v1/agencies/route
Public
Calculates driving route geometry and estimated transit distance to parking facility.
Accepts origin coordinates (user location) and destination coordinates (agency location).
🔍 Query Parameters
origin_lat=22.5726&origin_lng=88.3639&dest_lat=22.5800&dest_lng=88.3700
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "distance_km": 1.4,
    "duration_mins": 5,
    "polyline": "a~l~Fcy}sO..."
  }
}
