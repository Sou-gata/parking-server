⭐ Ratings & Reviews APIs
rating.routes.js
POST /api/v1/ratings
verifyJWT
Submits a customer rating (1 to 5 stars) and review text for a completed parking reservation.
📥 Request Body (JSON)
{
  "agency_id": "agency_881",
  "booking_id": "bk_99012",
  "rating_val": 5,
  "review_text": "Spacious parking lot with quick gate operator check-in!"
}
📤 Sample Response (201 Created)
{
  "statusCode": 201,
  "data": { "rating_id": "rat_101", "rating_val": 5 },
  "message": "Rating submitted successfully"
}
GET /api/v1/ratings/agency/:agencyId
Public
Fetches customer ratings and written reviews for a target parking agency.
📌 Path Parameters
agencyId: string (e.g. agency_881)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": {
    "average_rating": 4.8,
    "total_reviews": 42,
    "reviews": [
      { "reviewer": "John D.", "rating_val": 5, "review_text": "Spacious parking lot..." }
    ]
  }
}
GET /api/v1/ratings/booking/:bookingId
verifyJWT
Fetches rating submitted by user for a specific booking (if already reviewed).
📌 Path Parameters
bookingId: string (e.g. bk_99012)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": { "rating_id": "rat_101", "rating_val": 5, "review_text": "Spacious..." }
}
GET /api/v1/ratings/user/my
verifyJWT
Lists all ratings and feedback reviews submitted by logged-in customer.
🔑 Headers Required
Authorization: Bearer <JWT_TOKEN>
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "data": [
    { "rating_id": "rat_101", "agency_name": "Metro Parking Hub", "rating_val": 5, "created_at": "2026-08-14T14:30:00Z" }
  ]
}
DELETE /api/v1/ratings/:id
verifyJWT super_admin
Deletes an offensive or spam review rating record.
📌 Path Parameters
id: string (e.g. rat_101)
📤 Sample Response (200 OK)
{
  "statusCode": 200,
  "message": "Rating deleted successfully"
}
